Ketentuan & Tarif Kas Bagi Order (BAGOR)

Dalam rangka menertibkan iklim bisnis rental mobil, mempererat persaudaraan sesama anggota ASPERDA, serta memperkuat kas kegiatan organisasi, setiap transaksi Bagi Order (Outsource Unit) dikenakan kontribusi kas wajib yang dibayarkan oleh Penerima Order (Pemilik Mobil yang menerima job).

Kelas Standard / MPV
Rp 5.000 / hari sewa

Contoh armada kendaraan:

  • Toyota Avanza / Veloz
  • Toyota Calya / Daihatsu Sigra
  • Toyota Innova Reborn / Grand New
  • Suzuki Ertiga / XL7
  • Mitsubishi Xpander / Brio / Mobilio
Contoh: 3 hari Innova = Rp 15.000 Kas Bagor
Medium / SUV / Microbus
Rp 10.000 / hari sewa

Contoh armada kendaraan:

  • Toyota Innova Zenix Q / V Hybrid
  • Toyota Fortuner / VRZ / GR
  • Mitsubishi Pajero Sport
  • Toyota Hiace Premio / Commuter
  • Isuzu Elf Long / Coaster
Contoh: 2 hari Fortuner = Rp 20.000 Kas Bagor
Mewah / Luxury VIP
Rp 50.000 / hari sewa

Contoh armada kendaraan:

  • Toyota Alphard / Vellfire
  • Toyota Camry / Accord
  • Mercedes-Benz C/E/S Class
  • BMW 3 / 5 / 7 Series
  • Mobil Mewah / Premium lainnya
Contoh: 2 hari Alphard = Rp 100.000 Kas Bagor

Prosedur Pembayaran Bagi Order:

  1. Pemilik Order menginput transaksi Bagi Order ke dalam sistem Bagor ASPERDA.
  2. Penerima Order mengonfirmasi kecocokan tanggal dan ketersediaan unit.
  3. Kas Bagor dihitung otomatis berdasarkan durasi hari × tarif kelas kendaraan.
  4. Penerima Order melakukan kewajiban penyetoran fee Kas Bagor ke Bendahara ASPERDA sebelum atau sesudah unit selesai bertugas.
